# 学习体验改进

## 课程路径

旧课程同样适用：默认收起明确的致谢、版权等附属内容，把引言、如何阅读、前置知识等归入可选导读。此默认规则依据标题，不能代替内容判断，因此提供“根据原文优化路径”，让模型结合各节开头片段重新判断；证据不足时保留正文。模型判断不是全文审阅。

筛选结果只改变导航分类，原始单元、来源、讲解和进度均保留。“查看导读与附属内容”可展开全部内容。仍停留在导读的用户可以手动点击“直接进入正文”；系统不擅自推进。后续“继续下一节”按正文路径导航。

优化路径会调用已配置模型，全部批次成功后才保存分类；失败可重试。本版同一课程复用一次路径优化任务。

## 更新旧讲解

已配置模型时，正文上方显示“按新方式更新本节”。点击会按当前教学策略重新生成，成功后归档旧版本并替换讲解；失败或取消时旧内容保留。章节不变，阅读位置回到本节开头。学习记录保留，旧练习结果不会套用到新版本；过期页面提交旧练习会被拒绝。

归档可通过 `/api/courses/{course_id}/units/{unit_id}/versions` 查看。当前没有回滚按钮。重新生成会消耗模型额度，重启本身不调用模型。

## 按需动态场景

选中正文后，选中文字自动进入提问上下文，用户可直接追问。模型可继续选用文字、类比、表格、正反例等；需要展示关系或变化时才生成场景。聊天中的场景通过“打开演示区”直接打开独立窗口。

场景由对象、分组边界、连线、状态帧和可切换情境组成。支持位置平滑过渡、沿线移动的信息标记、状态展示、播放暂停、拖动时间线、放大和减少动态效果设置。使用 Vue 与浏览器原生 SVG/CSS，没有移植第三方动画框架源码。

模型生成声明式场景数据，不直接执行生成的 JavaScript。服务端检查对象引用、唯一性、画布边界和规模。场景是教学示意，不是实际代码执行、物理仿真或任意 PPT 动效引擎。原有步骤图为旧内容保留；要获得新场景需更新讲解或发起新追问。

真实验证：使用自编公开概念说明，DeepSeek 一次调用生成“允许写入／禁止写入”两个情境，约 7.8 秒，4290 token。隔离预览中检查了放大、情境切换和拖动时间线；未改动用户学习资料。样例发现模型可能把会变化的状态写入固定节点名称，已在策略中明确区分稳定名称和动态状态；该约束效果仍需后续多例验证。单次成功不代表所有内容都能可靠生成。

最终自动检查：18 项后端测试；前端 TypeScript 检查和生产构建。已增加旧后台版本提示。如果页面提示旧版本，请停止原进程，用 `scripts/dev.py` 重启后刷新。运行构建版时需要重新构建；本次已构建。

## 演示入口修复与界面精简

移除“正文优先；导读和致谢仍可查看。”及逐块的“帮我理解这段／在演示区讲解”按钮，保留鼠标选中文字后直接提问。

原来的演示入口仅在正文顶部插入内容，阅读位置较靠下时可能看不到反馈。现改为原生 dialog 独立窗口，显示在页面顶层，支持关闭按钮、Esc 和点击窗口外部关闭。关闭时返回打开按钮的焦点，不改变学习进度。浏览器已验证从聊天打开、切换情境、拖动时间线、Esc 关闭与重新打开；TypeScript 检查和生产构建通过。本次未改后端行为，也未调用模型。
