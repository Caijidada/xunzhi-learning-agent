# 完整学习与专注体验

完整学习默认启用，按每批 4 个片段处理本节全部已提取原文。已完成批次写入检查点，失败重试不重复调用已完成批次。每个片段另以“原文对照”保留原始提取文本，包括代码，不依赖模型是否在讲解里选择展示。界面显示纳入片段数；这不是语义覆盖率，也不能保证 PDF 中图片或提取失败的内容完整。

快速模式仅处理前 7 个片段，适合预览，界面显示明确范围。切换模式后需“按新方式更新本节”；不会自动覆盖旧讲解或调用模型。完整模式耗时与调用量随材料长度增加。

代码支持行号和按行提问。模型可输出关联实际行范围的逐步推演，展示解释与变量状态；这是教学推演，并未在运行环境中执行。代码未生成推演时仍可逐行阅读。新生成的视觉演示应使用场景而非旧式高亮步骤卡，旧内容不会自动改写。
