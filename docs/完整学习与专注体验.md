# 完整学习与专注体验

完整学习默认启用，按每批 4 个片段处理本节全部已提取原文。已完成批次写入检查点，失败重试不重复调用已完成批次。每个片段另以“原文对照”保留原始提取文本，包括代码，不依赖模型是否在讲解里选择展示。界面显示纳入片段数；这不是语义覆盖率，也不能保证 PDF 中图片或提取失败的内容完整。

快速模式仅处理前 7 个片段，适合预览，界面显示明确范围。切换模式后需“按新方式更新本节”；不会自动覆盖旧讲解或调用模型。完整模式耗时与调用量随材料长度增加。

代码支持行号和按行提问。模型可输出关联实际行范围的逐步推演，展示解释与变量状态；这是教学推演，并未在运行环境中执行。代码未生成推演时仍可逐行阅读。新生成的视觉演示应使用场景而非旧式高亮步骤卡，旧内容不会自动改写。

左右侧栏开关固定在顶部工具栏，目录内开关也保持在滚动容器顶部。桌面问答栏左边缘可拖动调整宽度，也可聚焦分隔条用方向键调整；消息区可纵向拉伸。收起状态和宽度在本机保存。手机布局保留收起开关，不提供宽度拖动。

专注计时支持开始、暂停、继续、结束和新一轮；使用截止时间计算，刷新后恢复。计时在后台继续，暂停时不计时；完成显示鼓励信息，不把计时当作实际专注证明。计时不发放经验，避免把后台挂机当学习成果。

每道课程练习首次答对 +1 XP，服务端判题并使用题目与选项标识去重，刷新、重复提交或重复答同题不会重复加分。奖励按课程保存。首次加载课程时按正文的章节顺序建立等级路线，每 3 XP 对应下一个章节等级；等级不锁章节，也不是掌握程度。现有历史答题不补发奖励，聊天中的体验练习暂不计经验。

演示画布不再在线上堆放关系文字：关系列表与对象状态独立显示，边界以颜色对应，长说明可完整展开。旧式步骤卡只作静态说明；新生成的顺序高亮 diagram 会被输出校验拒绝并要求改为真实场景或文字／代码。
