# 开发进度与续接记录

更新：2026-11-05。当前完成 PDF 学习工作台的首个可运行版本，完整愿景尚未全部实现。

## 已确认的约束

- 用户本人先使用，2–3 周做可演示版本，Python 后端与 Vue 前端。
- 真实模型提供商：DeepSeek。密钥由用户在本机 `.env` 填入，不要求发送到聊天。
- 用户决定何时进入下一章；练习不构成通关门槛。
- 每日任务跟随实际进度，互动展示按内容和困惑决定。
- 优先成熟开源库；借鉴设计和复制源码必须区分，保留许可证。

3. DeepSeek 兼容接口，JSON 结构和引用 ID 校验，最多一次修复尝试；模型配置、额度、网络错误反馈。

5. 当前小节与阅读位置持久化，乐观版本校验；自述理解、困惑、练习和更正记录。

8. Vue 学习、资料库、记忆页面；本机启动脚本、依赖锁定和说明。

## 下一轮优先事项

教学策略更新：已解除固定教学顺序，问答加入当前讲解与自由教学方法记录。详见 [教学策略验收](教学策略验收.md)。这是自适应教学的基础改动，尚未验证真实模型效果；课程筛选与场景动画需求仍待实现。

1. 接入用户本机 DeepSeek 密钥后，用同一组真实教材问题验收：正确解释、材料不足澄清、困惑后的策略选择、模型错误恢复。记录延迟和 token，人工逐条检查引用是否支持结论。
2. **长小节覆盖**：当前取前几个片段生成一节，可能遗漏后文。应先把长目录小节拆成有覆盖清单的微课，再逐节生成；不能以“生成成功”代表整节学完。
3. 大纲编辑及版本绑定；学习记录绑定内容版本，避免内容变化后误读旧练习。
4. 完成桌面与移动端浏览器验收：导入、取消、来源、选中追问、答题、记录更正、切节和刷新恢复。
5. 实现选题入口与可信来源研究：优先官方文档、原始论文、官方代码；记录来源等级和抓取日期，不能只靠域名推断正确性。
6. 独立代码运行区：优先浏览器隔离的 Python 运行环境，超时、终止和资源限制。禁止直接在后端执行模型生成代码。
7. 真实评测集：来源支持率、引用定位准确率、进度恢复成功率、重复请求重复副作用数、困惑问题解决情况。学习效果用延迟复测观察，不能只用“感觉更好”。

## 当前限制

无 OCR、无联网选题搜集、无向量库、无任意动画或代码执行、无账户系统。当前使用 SQLite 和 BM25；“记忆”是可更正的结构化事件与近期历史，不是完整长期知识掌握模型。逐块恢复发生在模型返回并验证整份 JSON 之后，不是模型 token 流式检查点。

## 如何继续

在项目根目录执行 `.venv/bin/python scripts/dev.py`，打开 `http://127.0.0.1:5173/`。首次安装与配置见 README。停止服务不会清空数据。

续接时先读 AGENTS.md、本文件和 README，再检查代码与 Git 状态，保留用户改动。首版以基线提交纳入 Git；后续每个独立功能或修复验证后提交，规范见 AGENTS.md。目录中已有研究材料和用户文件，不应清理。若额度不足，下次从这里继续；本项目未设置自动唤醒或自动恢复额度的机制。
